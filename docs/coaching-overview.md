# 可能性LABO キャリアコーチング — 事業内容まとめ（システム実装の前提）

> 出典：可能性LABO コーチ向け業務マニュアル v1.0 ＋ 運用ヒアリング。
> プロファイルシステム（`app/`）にコーチング機能を統合していく際の正本メモ。

## 1. 理念・目的
- 20〜30代の転職検討層が「自分の可能性に気づき、自走できる」ようになるためのキャリアコーチング。
- 転職エージェント（企業ありき）と違い「その人の人生ありき」で伴走。価値観・転職観を押し付けない。
- 最終ゴールは **人材紹介サービスへの接続（送客）**。

## 2. プラン（価格確定）
| | スタンダード | フル |
|---|---|---|
| 価格 | **¥80,000** | **¥150,000** |
| 期間/回数 | 1ヶ月 / 全4回 | 2ヶ月 / 全8回 |
| 1回 | 週1 × 60分 | 週1〜2 × 60〜90分 |
| 範囲 | 方向性を決めるまで | スタンダード＋転職実務まで伴走 |
| 成果物 | キャリアプランシート | 3点セット（プランシート／職務経歴書添削／面接FB） |

> マニュアル内に ¥50,000/¥100,000 の記載もあったが **正は ¥80,000/¥150,000**。

## 3. セッション設計
- スタンダード(4)：①自己分析 ②市場価値診断 ③方向性決定 ④行動計画
- フル(8)：①〜③＋ ④職務経歴書作成 ⑤書類添削・応募開始 ⑥面接対策 ⑦模擬面接 ⑧振り返り・内定後フォロー
- 1回60分＝チェックイン5/本題45/アクション確認8/チェックアウト2。聞き役7:話し役3。
- 記録必須(毎回)：実施日時／サマリー(3〜5行)／次回アクション／所感・懸念／次回テーマ。**24h以内に議事メモ送付**。

## 4. 行動規範（抜粋）
- 受け止める・質問で気づきを促す。価値観の押し付け、特定企業の強い推奨、**LABO経由以外の転職先紹介**、個人SNS相談、個人情報外部共有は禁止。
- 迷ったら必ず管理者に先に相談。Zoomはコーチがホスト・前日にLINEでリンク再送・原則録画なし。

## 5. 集客〜コーチングのファネル（確定）
```
① 無料体験予約 → ② 無料体験(面談)完了 → ③ 決済 → ④ コーチング(4/8回) → ⑤ 完了 → 人材紹介へ接続
```
- ① は予約ページから自動登録（連携済み）。
- ③ 決済が ②→④ のゲート。
- 職業タイプ診断（無料）→ 連携コードで適性が候補者に引き継がれ、①〜④の自己分析素材になる。

## 6. 決済・運用（ヒアリング反映）
- **決済方法：Stripe 等のオンライン決済を予定**（体験完了後に案内 → 入金で「コーチング中」へ）。
- **誰が決済案内／入金確認するか：未定**（→ 実装は特定の担当に固定せず、誰でも案内・確認・記録できる柔軟な形にしておく）。
- **事前ヒアリングシートの設問：なし**（現時点。将来追加され得る）。

## 7. システムへの対応方針
- **ステージ**を候補者に1つ持たせ、一覧をファネルで運用（無料体験予約／体験完了／コーチング中／完了／見送り）。
- コーチング実務は候補者プロファイルの **コーチングタブ**（プラン・全セッション記録・入金・完了報告）で管理（実装済み）。
- 決済（Stripe）は ②→④ ゲートに後付けする層（Payment Link 等）。運用担当が未定のため、UIは「誰でも操作できる」前提で作る。
- 送客ステータス（紹介中/内定/決定…）は「完了」以降の別レイヤーとして共存。

## 8. ステージUI設計（確定・実装済み v1）
- **ステージ（5）**：無料体験予約(info) / 体験完了(cyan) / コーチング中(warn) / 完了(good) / 見送り(muted)。本線は前4段、見送りは別扱い。
- **一覧＝カンバン/リスト トグル**（既定カンバン）
  - カンバン：本線4段の列にカード。各カードのセレクトでステージ変更（**ドラッグは無し v1**）。
  - リスト：詳細カード＋ステージのチップ絞り込み（件数バッジ）。
  - カード表示：ステージバッジ／プラン(n回 or 総合スコア)／タイプ／セグメント。
- **プロファイル＝ステップバー**：現在地ハイライト＋クリックで移動、見送りは右端チップ。
- **データ**：`Candidate.stage`（既定「無料体験予約」）。予約ページ経由・新規追加は自動で「無料体験予約」。Supabase は `candidates.stage`（CHECK制約）。
- **決済（Stripe）**：体験完了→コーチング中ゲートに後付け（未実装・運用担当未定のため誰でも操作可の前提）。
