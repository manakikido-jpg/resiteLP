## 機能ID の付け方

カテゴリごとに百番台を割り当て、通し番号にする。
**一度振った番号は変えない。** 番号でドキュメント間を参照するため。

| 番号帯 | カテゴリ |
|---|---|
| 100 | 基盤・デプロイ・認証 |
| 200 | 集客（LP・計測） |
| 300 | 職業タイプ診断 |
| 400 | 公開予約 |
| 500 | 候補者マイページ |
| 600 | 管理アプリ（候補者・面談・コーチング） |
| 700 | お知らせ配信 |

  OGP/canonical の12箇所も新ドメインに書き換えた。

  匿名に件数だけを返す `slot_counts()`、定員と過去日時を検査する `assert_slot_bookable()`、

  失敗時は「何が起きて次にどうするか」を表示するようにした。**migration 0005 の適用が必要。**
